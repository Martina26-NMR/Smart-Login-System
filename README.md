# Smart Login System

A simple front-end login and sign-up system using HTML, CSS (Bootstrap), and JavaScript.  
The project stores user credentials in `localStorage` to simulate authentication without a backend.

## 🚀 Features

- Sign Up with name, email, and password
- Prevent sign-up with an already registered email
- Login with previously saved credentials
- Personalized welcome message after login
- Alerts and validation for missing or incorrect fields
- Responsive design using Bootstrap

## 🛠 Technologies Used

- HTML5
- CSS3 + Bootstrap 5
- JavaScript (Vanilla)
- DOM
- OOCSS
- BEM
- localStorage for saving user data


## 🧠 How it Works

1. On sign-up, user credentials (name, email, password) are saved in `localStorage`.
2. On login, entered email and password are checked against saved data.
3. If valid, user is redirected to the welcome page with their name displayed.
4. If invalid or missing fields, appropriate error messages are shown.

## 📌 Notes

- This project is purely front-end and not secure for production use.
- localStorage is used for demonstration purposes only.
- Future versions can be extended with Firebase or a real backend.
